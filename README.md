# AtCoder Local Judge

AtCoder を JavaScript (Node.js) で解くための、自分専用のローカル実行環境です。
コードとテストケース(入力と期待する出力)を入力して実行すると、ケースごとに AC / WA / TLE / RE などの判定、実行結果、実行時間を表示します。

サーバは `127.0.0.1` でのみ待ち受けるので、外部には公開されません。

## 主な機能

- **ケースごとの判定**:AC / WA / TLE / RE / OLE を判定し、実行時間を ms 単位で表示します
- **逐次表示**:1ケース終わるごとに結果が届きます。未完了のケースは WJ(ジャッジ待ち)と表示されます
- **期待する出力を空欄にしたケース**:判定せず、実行結果だけを表示します
- **標準エラー出力**:何か出力されたときだけ表示します。`console.error()` でデバッグ出力をしても判定には影響しません
- **コードエディタ**:VS Code と同じ Monaco Editor を使っていて、シンタックスハイライトと補完が効きます
- **レイアウト**:テストケース欄とコード欄の間のバーをドラッグして幅を変えられます。左右の入れ替えもできます
- **テーマ**:ダークモードとライトモードを切り替えられます。初期状態では OS の設定に従います
- **自動保存**:コード、テストケース、実行時間制限、レイアウトはブラウザに自動保存されます
- **依存パッケージなし**:`npm install` は不要で、Node.js だけで動きます

## 必要なもの

- Node.js 18 以上
- インターネット接続:エディタ(Monaco)とフォントを CDN から読み込むため。オフラインのときは普通のテキストエリアで動きます

## 使い方

### Windows

`start.bat` をダブルクリックすると、サーバが起動してブラウザが自動で開きます。
サーバを止めるときは、黒いウィンドウで `Ctrl+C` を押すか、ウィンドウを閉じてください。

ポート番号を変えたいときは、`start.bat` の次の行を書き換えます。

```bat
set PORT=3000
```

### その他の OS / 手動で起動する場合

```sh
node backend/server.js
```

起動したら http://localhost:3000 を開いてください。ポートは環境変数 `PORT` で変更できます。

```sh
PORT=8080 node backend/server.js
```

### 操作

| 操作 | 内容 |
| --- | --- |
| `Ctrl+Enter`(Mac は `⌘+Enter`) | 実行 |
| 分割バーをドラッグ | テストケース欄とコード欄の幅を変更 |
| 分割バーをダブルクリック | 幅を初期状態に戻す |
| 分割バーを選択して `←` `→`(`Shift` で大きく移動) | キーボードで幅を変更 |
| 「ひな形を入れる」 | Scanner クラス入りのテンプレートに置き換え(`Ctrl+Z` で戻せます) |
| 「すべてクリア」 | テストケースを空のケース1つだけに戻す |

### 入力の読み方

ひな形では、標準入力を空白区切りで読む `Scanner` クラスを用意しています。

```js
function main(){
  const sc = new Scanner();
  const N = sc.nextInt();        // 数値として読む
  const S = sc.next();           // 文字列として読む
  const X = sc.nextBigInt();     // BigInt として読む(2^53 を超える整数)
}
```

Windows では `/dev/stdin` が使えないため、標準入力は `readFileSync(0, 'utf8')` で読んでいます。
この書き方は AtCoder 上でもそのまま動きます。

## 判定について

| 判定 | 意味 |
| --- | --- |
| AC | 正解 |
| WA | 不正解 |
| TLE | 実行時間制限超過 |
| RE | 実行時エラー(終了コードが 0 以外) |
| OLE | 出力サイズ超過(32 MiB) |
| IE | 内部エラー(プロセスを起動できなかったなど) |
| DONE | 実行のみ(期待する出力が空欄) |
| WJ | ジャッジ待ち(実行中) |

- 出力の比較では、各行の行末の空白と、末尾の空行を無視します
- 総合判定は IE > RE > OLE > TLE > WA > AC の優先順で決まります。DONE のケースは総合判定に含みません
- 実行時間には Node.js の起動時間(数十 ms)が含まれるため、AtCoder 上より少し長めに出ます
- TLE になっても、制限の 2 倍(最大で制限 + 5 秒)までは待ってから強制終了します。どのくらい遅いかの目安になります
- 実行時間の計測がぶれないよう、ケースは並列ではなく 1 つずつ順番に実行します
- 実行時のオプションは AtCoder に合わせて `--max-old-space-size=1024` を付けています

## API

### `POST /api/run`

リクエスト(JSON)

```json
{
  "code": "console.log(1)",
  "timeLimitMs": 2000,
  "testCases": [
    { "input": "", "expected": "1\n" }
  ]
}
```

レスポンスは NDJSON(`application/x-ndjson`)で、1 行に 1 つの JSON が入っています。
ケースが 1 つ終わるたびに 1 行送られ、最後のケースの行にだけ総合判定(`summary`)が付きます。

```
{"type":"case","index":0,"result":{"status":"AC","timeMs":41,"stdout":"1\n","stderr":"","exitCode":0}}
{"type":"case","index":1,"result":{"status":"WA","timeMs":39,"stdout":"2\n","stderr":"","exitCode":0},"summary":{"overall":"WA","maxTimeMs":41,"nodeVersion":"v22.x.x"}}
```

途中で内部エラーが起きたときは `{"type":"error","error":"..."}` が送られます。
実行を始める前のエラー(コードが空、テストケースがないなど)は、通常の JSON `{"error":"..."}` として 400 番台のステータスで返ります。

### 制限

| 項目 | 上限 |
| --- | --- |
| ソースコード | 512 KiB |
| テストケース数 | 100 |
| 実行時間制限 | 0.1 〜 20 秒 |
| 標準出力 | 32 MiB |
| 標準エラー出力 | 64 KiB(超えた分は切り捨て) |
| 同時実行 | 1 件(実行中に次のリクエストが来ると 409 を返す) |

## セキュリティについて

自分のコードを手元で試すためのツールです。外部に公開する前提では作っていません。

- `127.0.0.1` でのみ待ち受けます
- DNS リバインディング対策として、`Host` ヘッダが `localhost` / `127.0.0.1` 以外のリクエストは拒否します
- 他のサイトのページからコード実行 API を呼ばれないよう、`Origin` ヘッダも確認します
- 実行するプロセスには、親プロセスの環境変数のうち `PATH` だけを渡します
- 実行中にブラウザを閉じたりリロードしたりすると、残りのケースは実行せず、実行中のプロセスも止めます

**ただしサンドボックスではありません。** 実行したコードは PC のユーザー権限でそのまま動き、ファイルの読み書きなども可能です。他人から受け取ったコードは実行しないでください。
